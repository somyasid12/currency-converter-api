# Currency Converter API

A simple currency converter built with Python and FastAPI. This project lets you convert amounts between different currencies using a free API.

## Features

- Convert between any two currencies.
- Interactive one-page interface in the browser.
- Shows results instantly.
- Handles invalid currency codes or empty inputs

## Tech Stack
- Python
- FastAPI
- Requests
- HTML/CSS/JavaScript (for the landing page)
- Frankfurter API (free, no API key required)
